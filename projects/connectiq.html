The problem

What it addresses

Developer profiles and project descriptions express similar skills in different words, making simple keyword matching restrictive.

My contribution

What I built

Built skill-vector extraction and compatibility scoring using sentence embeddings and cosine similarity.

  • Extracts skill vectors from profiles and compares them with project requirements using sentence embeddings.
  • Computes an opportunity score that quantifies alignment between a candidate and a project.
  • Presents recommendations in an interactive Streamlit interface.

The outcome

What the project delivers

An interactive interface presenting compatibility scores and opportunity recommendations.
