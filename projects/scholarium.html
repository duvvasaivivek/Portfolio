The problem

What it addresses

A learning goal needs structure: prerequisite topics, a sequence to follow, and a way to identify gaps along the way.

My contribution

What I built

Built the React and Django REST application, integrated roadmap generation, implemented authenticated APIs, and connected assessments with session analytics.

  • Generates DAG-based learning roadmaps through prompt engineering with Gemini 2.0 Flash, with Anthropic Claude as the fallback model.
  • Uses PostgreSQL for relational state and MongoDB for LLM response caching and token telemetry.
  • Caches prompts by MD5 hash to avoid redundant API calls and reduce latency.
  • Includes an assessment engine with binary-scored multiple-choice questions and session analytics to surface knowledge gaps.
  • Serves a React 18 single-page application through Django REST Framework APIs with JWT authentication.

The outcome

What the project delivers

A full-stack application combining interactive learning roadmaps, generated quizzes, response caching, and knowledge-gap tracking.

The application separates relational user state from cached model responses, while a fallback model provides a second generation path.
