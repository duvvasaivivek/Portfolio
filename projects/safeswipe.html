The problem

What it addresses

Fraud detection requires finding rare suspicious transactions while controlling false positives in highly imbalanced data.

My contribution

What I built

Combined XGBoost classification with Local Outlier Factor anomaly detection, tuned decision thresholds, and exposed scores through an API and Streamlit dashboard.

  • Combines supervised classification (XGBoost) with unsupervised anomaly detection (Local Outlier Factor).
  • Handles extreme class imbalance with precision-focused metrics and decision-threshold tuning to control false positives.
  • Exposes transaction scores through an API and an interactive Streamlit dashboard.

The outcome

What the project delivers

An end-to-end workflow connecting transaction data, risk scoring, and an interactive interface for inspecting results.

The classification threshold is an operating decision. Precision and recall need to be considered together when reviewing rare-event predictions.
